# UAT 测试用例 — Codex Switch v1.13.0

> **测试环境**: macOS arm64, Codex Desktop v0.140+  
> **安装包**: `release/Codex-Switch-1.13.0-mac-arm64.dmg` (92MB)  
> **测试工具**: Codex Desktop（图形界面）  
> **测试日期**: 2026-06-19

---

## 版本变更说明

v1.13.0 核心变更：

- 删除了自己实现的 LLM compact（LLM 摘要压缩）
- 删除了 ndjson 对话持久化，改为纯内存缓存（500 条）
- 缓存未命中时从 Codex 原生 sessions JSONL 回退读取
- `/v1/responses/compact` 端点返回空 stub，避免 Codex Desktop 报错
- Codex config.toml "保存并应用"时写入上下文窗口配置（1M token 窗口）
- DeepSeek 上下文超限时翻译为中文提示

---

## 安装前准备

1. 确保 Codex Desktop 已安装且能正常启动
2. 打开 DMG：双击 `Codex-Switch-1.13.0-mac-arm64.dmg`
3. 拖动 Codex Switch 到 Applications 文件夹
4. 首次启动可能需要右键 → 打开（未签名应用）
5. 确认 `~/.codex/config.toml` 存在且已备份（Codex Switch 启动时会自动备份）
