一、写在前面：我被"装软件"折磨了一个月

最近这段时间，我帮挺多朋友装 Codex（OpenAI 官方的 AI 编程工具），让他们能用上又便宜又好的 DeepSeek。

本来我以为这事很简单，毕竟我之前已经写好了一个一键安装脚本：

🧰 codex-deepseek-installer
https://github.com/Mark7766/codex-deepseek-installer

但真到带着朋友们一步一步装的时候，我发现——不是工具不好，是门槛太高了。

问题 1：命令行，是真的会"劝退"普通人

我以为打开终端、复制一行命令、回车就完了。结果在 Windows 朋友那边，光是"在哪里打开命令提示符"就要解释 5 分钟，再加一句"右键以管理员身份运行"，对方已经开始 怀疑人生。

更不用说，安装脚本之前还有 三个准备工作：申请 DeepSeek 账号并充值、创建 API Key、装 Git、装 Node.js……每一步对开发者来说都"so easy"，但对小白朋友来说，每一步都像在过雷区。

📷 [配图占位：朋友发来的命令行报错截图 / 一脸懵的聊天记录]

问题 2：装好以后，看到"黑乎乎的窗口"又懵了

就算克服了千难万险把 Codex CLI 装上了，打开一看——一个黑黢黢的命令行窗口，光标"咣咣"在闪。

很多朋友的第一反应是："这……就是 AI 编程？我是不是装错了？"

是的，命令行版的 Codex 上手成本对普通用户太高了。

二、于是我熬了两个通宵，做了 Codex Switch

那干脆就别让大家碰命令行了。
我做一个图形化的桌面 App，朋友们装好之后只用做一件事：

把 DeepSeek API Key 填进去，点一下"启动"。
完事。

这个 App 叫 Codex Switch，定位很简单：

  • 给 Codex 桌面版（也就是 Codex 官方的 GUI）挂上 DeepSeek 的引擎；
  • 不用碰命令行，不用装 Git/Node，不用记任何配置；
  • 跨平台：macOS 和 Windows 都有安装包，双击就能装；
  • 界面对标 Claude Desktop 的简洁风格，干干净净。
📷 [配图占位：Codex Switch 主面板截图 —— 显示"代理运行中"状态]

三、用起来到底有多简单？三步

第 1 步：装 Codex 桌面版

双击 dmg / exe 安装包，下一步下一步装完。

第 2 步：装 Codex Switch

同样双击 dmg / exe，装完打开，里面会引导你填一次 DeepSeek API Key。

第 3 步：点一下"启动代理"

Codex Switch 会自动帮你写好 Codex 的配置文件，让 Codex 桌面版直接走 DeepSeek。
然后你就可以打开 Codex 桌面版，正常用 AI 写代码了。全程没有一行命令行操作。
