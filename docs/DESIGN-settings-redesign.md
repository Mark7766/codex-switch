## 1. 现状问题

当前设置页面从用户视角来看，信息过载且重点不突出：

```
现状布局：
  API Key            ← 重要
  代理与模型          ← 重要
    · 端口
    · 模型
    · 自动启动
    · 拦截建议气泡
    · 保存并应用      ← 核心操作，但淹没在段落中间
  Codex 配置备份      ← 占一整屏（备份列表 + 清空 + 文件数）
  对话记录来源        ← 重要，但被备份挤到很下面
  Claude 工具接入     ← 279 行，展开全部配置细节
  自动更新            ← 重要
  体验优化计划
```

核心问题：

1. **"保存并应用"按钮被淹没**——用户在设置页最重要的操作，却藏在「代理与模型」Section 底部
2. **备份信息过度曝光**——config.toml 和 auth.json 的完整备份列表常年占一整屏，99% 的时间用户不需要看
3. **Claude 工具接入太臃肿**——279 行组件，包含四种工具的安装状态、配置路径、备份还原，全部平铺
4. **核心设置不够突出**——API Key、模型、端口才是用户每次打开设置想看到的东西

## 2. Apple 设计哲学对标

Apple 的设置 App 有几个核心原则：

| 原则                 | 说明                                  |
| -------------------- | ------------------------------------- |
| **最重要的在最上面** | Apple ID 在设置页第一行               |
| **详情用折叠**       | iCloud 备份详情、存储管理——点进去才有 |
| **一行一个设置**     | WiFi 开关、蓝牙开关——不展开说明文字   |
| **稀有操作用红色**   | "删除账户"永远在最底部，用红色警示    |
| **Section 之间留白** | 用间距而非分割线表达信息层级          |

> "A setting that 99% of users never change should take 1% of the screen. A setting every user needs should take 99%."

### 3.1 关键变化

**变化一：Codex 配置一个 Section 搞定**

不再拆分「代理与模型」+「对话记录来源」+「配置备份」三个独立 Section。本质都是 Codex 的配置管理——两头切：Switch 代理 ↔ OpenAI 官方。合并为一个干净的面板：

```
  Codex 配置
    端口 / 模型 / 自动启动 / 拦截建议
    ● Codex Switch   ○ OpenAI          ← 两头切
    [ 保存并应用 ]     [ 恢复 ] ▾       ← 保存写入，恢复还原备份
```

`[恢复]` 默认还原**最新备份**（90% 的用户场景）。右侧 ▾ 展开备份列表，选历史版本。

**变化二：去掉独立的「配置备份」Section**

备份管理不再是一个独立区域。它退化为每个工具的 `[恢复]` 按钮下的一个下拉。点 ▾ 选择具体版本，不点就默认最新。Codex 有，Claude Desktop 有，Claude CLI 也有——但都藏在一个 ▾ 里。

**变化三：Claude Desktop / Claude CLI 各自折叠**

不再合并成「Claude 工具接入」一个 Section。分开更直观——用户一眼看到自己用的工具。每个折叠行的内容极简：状态 + 两个按钮。

```
  Claude Desktop     ▸  ← 折叠，一行
  Claude Code CLI    ▸  ← 折叠，一行
```

Codex Desktop 和 Codex CLI 的状态在主面板 Dashboard 已有，不需要在设置里重复。

| :--: | --------------- | :--------------: |
|  1   | API Key         |       展开       |

从 9 个 Section 精简到 7 个。去掉独立备份、去掉独立对话来源、拆开 Claude 工具。

## 5. 用户体验对比

| 场景             | 现状                                          | 新方案                                   |
| ---------------- | --------------------------------------------- | ---------------------------------------- |
| 改个端口号       | 找到「代理与模型」→ 改端口 → 找「保存并应用」 | Codex 配置一个面板全搞定                 |
| 切回 OpenAI      | 滚到「对话记录来源」→ 点切换                  | Codex 配置面板内，配置来源开关一键切     |
| 还原最新备份     | 找到「配置备份」→ 翻列表 → 找最新 → 点还原    | 点 `[恢复]` 按钮，默认最新               |
| 保存 Claude 配置 | 展开 279 行 → 找到保存按钮                    | 点 Claude Desktop ▸ → `[保存并应用]`     |
| 整体视觉         | 9 个 Section，信息密度高                      | **7 个 Section**，一屏看完，折叠区不打扰 |
